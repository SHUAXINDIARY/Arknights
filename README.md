# 明日方舟生涯生成器

一个记录与分享明日方舟游玩经历的在线工具。选择干员、时装、活动与蚀刻章，填写自己的偏好，即可生成生涯展示页并导出 PNG 图片。

[在线使用](https://arknights.shuaxinjs.cn/)

## 功能

- 记录主力干员、首个六星、开荒伙伴，以及按星级、职业、性别划分的喜爱干员。
- 选择第一件购买的时装、最喜欢的时装、首次参加的活动、喜欢的剧情与蚀刻章套组。
- 填写游戏昵称、常驻玩法、EP 与期待实装的角色；头像可从游戏头像、干员头像和蚀刻章中选择。
- 搜索选择项，查看填写进度，预览示例并继续编辑。
- 生涯表单保存在当前浏览器的 `localStorage` 中，刷新后可继续填写。
- 支持中文、English、日本語界面，以及干员和时装名称的国际化；缺少译名时回退到中文。
- 导出完整结果区域为 PNG，支持页面转场、交互动画和减少动态效果偏好。

## 使用指南

### 编辑页 `/`

1. 选择或填写至少一项数据，点击「生成」进入结果页。
2. 「预览示例」会将示例数据写入当前生涯表单并打开结果页，**覆盖此前保存的填写内容**。
3. 点击页面顶部的语言按钮，可在抽屉中切换语言或访问相关资料站。

### 结果页 `/result`

- 点击「编辑」返回编辑页，保留已填写的数据。
- 点击「导出结果」下载 `Arknights.png`。截图覆盖完整结果容器（包含操作按钮），不受当前滚动位置限制，并以 3 倍分辨率生成。
- 建议使用独立浏览器导出。内嵌浏览器、Safari 和远程图片的跨域限制可能影响下载或渲染效果，无法保证所有环境一致。

导出实现先检测实验性的 HTML-in-Canvas 能力，不支持或失败时回退到 `dom-to-image → SVG → Canvas`。更多细节见[导出说明](./src/utils/screenshot.md)。

## 技术栈

- **前端**：React 19、TypeScript、React Router 7。
- **构建与样式**：Rsbuild、Tailwind CSS 3、仓库内维护的 React/CSS UI 组件。
- **交互与状态**：Framer Motion、ahooks、next-themes。
- **国际化**：i18next、react-i18next。
- **图片导出**：dom-to-image、Canvas、file-saver。
- **数据维护**：Puppeteer、tsx、ArknightsGamedata Git 子模块。

## 本地开发

准备 Node.js（建议使用 LTS 版本）、Git 和 pnpm 10.26.0（版本由 `package.json` 指定）。

```bash
git clone https://github.com/SHUAXINDIARY/Arknights.git
cd Arknights
pnpm install
pnpm dev
```

访问终端输出的本地地址。前端直接使用仓库已有数据，启动和构建不需要先抓取 PRTS 或初始化游戏数据子模块；运行数据更新脚本时才需要子模块。

### 常用命令

| 命令 | 用途 |
| --- | --- |
| `pnpm dev` | 启动开发服务器 |
| `pnpm build` | 生成生产构建，输出至 `dist/` |
| `pnpm preview` | 本地预览已生成的生产构建 |
| `pnpm lint` | 执行 ESLint 检查 |
| `pnpm init:submodule` | 初始化并检出游戏数据子模块 |
| `pnpm update:submodule` | 更新子模块至远端最新提交 |
| `pnpm update:prts` | 抓取 PRTS 并更新生成数据 |
| `pnpm update:international` | 使用子模块补充干员与时装译名 |
| `pnpm auto` | 依次执行 PRTS 抓取、子模块更新、国际化数据更新 |

### 构建与部署

```bash
pnpm build
pnpm preview
```

`dist/` 可部署到 Cloudflare 等静态站点托管服务。应用使用浏览器路由，托管服务需支持将 `/result` 等前端路由回退至 `index.html`，以便直接访问或刷新。

仓库中的 [GitHub Actions 工作流](./.github/workflows/deploy.yml) 用于更新数据，未包含站点部署步骤。

## 数据维护

### 数据来源

- [PRTS Wiki](https://prts.wiki/w/%E9%A6%96%E9%A1%B5)：自动抓取干员、时装、头像、活动、蚀刻章及套组。
- [ArknightsGamedata](https://github.com/ArknightsAssets/ArknightsGamedata)：以 `scripts/ArknightsGamedata` 子模块接入，提供中、英、日游戏数据与译名。
- [B 站明日方舟 Wiki](https://wiki.biligame.com/arknights/%E9%A6%96%E9%A1%B5)：原有资料来源之一。

`src/data/` 保留基础数据，各数据模块将其与 `AutoGenerateData.ts` 合并去重后供页面使用。

### 手动更新

在仓库根目录执行，确保可以访问数据源，并已安装 Puppeteer 使用的 Chrome：

```bash
pnpm init:submodule
pnpm exec puppeteer browsers install chrome
pnpm auto
```

子模块已初始化后，可按需单独执行 `pnpm update:prts`、`pnpm update:submodule` 或 `pnpm update:international`。PRTS 脚本也会读取子模块用于译名映射，因此单独抓取前同样需要初始化子模块。

更新脚本会改写 `src/data/AutoGenerateData.ts`，子模块更新也可能改变其提交指针；提交前请检查差异。PRTS 新数据排在已有生成数据之前，并去除重复项。

[数据更新工作流](./.github/workflows/deploy.yml) 每天北京时间 10:00（UTC 02:00）定时触发，也支持手动触发；流程安装浏览器、执行 `auto`，然后提交并推送变化。

### 干员抓取验证

仓库提供分页抓取回归测试，使用本地页面验证延迟加载、分页及缺页报错；需要 Puppeteer 浏览器：

```bash
pnpm exec tsx --test scripts/prtsOperators.test.ts
```

如需验证当前 PRTS 站点，可启用联网测试（不写入数据文件）：

```bash
PRTS_LIVE_TEST=1 pnpm exec tsx --test scripts/prtsOperators.test.ts
```

## 目录结构

```text
src/
  pages/Home/           生涯编辑页
  pages/Result/         结果展示与导出
  components/          本地 UI、搜索选择器、图片与表单组件

  utils/screenshot.ts  PNG 导出实现
scripts/
  getDataFromPrts.ts    PRTS 数据抓取入口
  prtsOperators.ts     干员列表分页提取
  prtsOperators.test.ts 干员抓取测试
  filterData.ts        国际化数据映射
  ArknightsGamedata/   游戏数据 Git 子模块（需初始化）
.github/workflows/
  deploy.yml           定时数据更新工作流
```
